# ConnectIT – IT Recruitment & Job Portal

## Overview

ConnectIT is a web-based recruitment platform developed to simplify the hiring process between IT recruiters and job seekers. The system allows recruiters to advertise job opportunities, manage applications, and schedule interviews, while applicants can browse available positions and submit applications online.

This project was developed as part of my Bachelor of Science in Information Technology studies and demonstrates full-stack web development, database design, and software engineering principles.

---

## Features

### Applicant Module

* User registration and login
* Browse available IT job opportunities
* Apply for jobs
* View application status
* Manage personal profile

### Recruiter Module

* Recruiter authentication
* Create, edit, and delete job listings
* View submitted applications
* Manage applicant information
* Schedule interviews
* Track recruitment progress

### Administrative Features

* Database-driven application
* Secure user authentication
* CRUD operations for jobs and applicants
* SQL Server database integration

## Database Structure

The system uses a relational database with entities including:

* Recruiter
* Applicant
* Job
* Application
* Interview

Relationships between these entities allow recruiters to manage vacancies while applicants submit and track applications.

## Installation

1. Clone the repository.

```bash
git clone https://github.com/Kamogelo24/CONNECTIT.git
```

2. Open the solution in Visual Studio.

3. Restore any required NuGet packages.

4. Configure the SQL Server connection string in the application's configuration file.

5. Create the database using the provided SQL scripts.

6. Build and run the project.
